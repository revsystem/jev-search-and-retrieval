# PDF取り込みの検証記録

実施日 2026-09-19 / 対象 `n1110000.pdf`（総務省『情報通信白書』令和8年版 第1章「個人におけるAI利用」、15ページ、9.6MB）

PDFは会話への添付で受領した。`www.soumu.go.jp` と `docs.typesafe.ai` は、このセッションのコンテナでも、
同一環境に新しく起動したコンテナでも、egressゲートウェイがCONNECTに403を返す（`connect_rejected`）。
迂回は試していない。

## 評価ラベルの較正

初期のルールは白書一般の語彙を仮定していたため、この章（個人におけるAI利用）にはほぼ当たらなかった。
実コーパスの語彙を数えたうえで8問を作り直した。較正で分かった点は2つある。

1点目。単位「%」の要求は使えない。図表から抽出される数値には単位が付かず、軸ラベルの `100(%)` だけが `%`
を持つ。「利用頻度」「リスク」「利用目的」を含むチャンクの `%` ヒットは0件、小数のヒットは 3/3・5/6・1/1 件だった。

2点目。小数の有無だけでは識別力がない。37チャンク中33件が小数を含む。一方、句点の密度は本文と図表を明確に
分ける（図表を丸ごと抽出したチャンクは `。/100字 = 0.00`、本文は 0.4〜1.2）。数字密度は重なりが大きく
（本文 p5-c1 が 0.27、図表 p13-c0 が 0.23）、判別に使えない。生成モデルが引用できるのは本文なので、
直接の根拠の条件を「主題語 + 小数 + 3文以上」とした。

較正後の分布（コーパス37チャンク）。

```
q01  grade3=3, grade2=5, grade1=12   日本における生成AIサービスの利用経験率は前年からどう変化したか
q02  grade3=3, grade2=10, grade1=7   米国・ドイツ・中国と比べて日本の生成AI利用経験率はどの水準か
q03  grade3=1, grade2=4, grade1=7    生成AIサービスを利用しない理由として何が挙げられているか
q04  grade3=4, grade2=4, grade1=4    年齢階層によって生成AIの利用状況はどう違うか（11%、内容を確認のうえ許容）
q05  grade3=2, grade2=1              生成AIサービスの利用頻度はどの程度か
q06  grade3=2, grade2=1, grade1=6    生成AIはどのような目的で利用されているか
q07  grade3=1, grade2=5, grade1=2    AIの利用に対してどのようなリスク意識が示されているか
q08  grade3=2, grade2=1, grade1=4    人々はAIをどのような存在にたとえているか
```

q08 だけ `min_sentences` を課していない。この設問の直接の根拠は順位表そのものであり、句点を持たないため。

## 評価セットの健全性

`jev-rag evaluate --offline-embeddings` で、字句ベースの代用埋め込みによる baseline を実コーパスに対して測った。

```
| pipeline | ndcg@5 | strict_ndcg@5 | recall@5 | precision@5 | mrr |
|---|---|---|---|---|---|
| baseline | 0.322 | 0.294 | 0.209 | 0.300 | 0.469 |
```

自明に解ける値でも解けない値でもなく、改善の余地が残る水準である。ラベルが退化していないことの確認にはなるが、
代用埋め込みでの測定なので Cohere Embed v4 の性能を示すものではない。
