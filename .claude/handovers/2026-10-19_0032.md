## 決定事項
- API キーはリポジトリの `.env` に置く。`~/.zshrc` は dotfiles リポジトリの `home/.zshrc` への symlink で、commit すると鍵が公開されるため
- 派生元はデフォルトブランチ。`feat/strands-decider-comparison` は記事のリンク先として残すもので、今回の比較とは独立させる
- Jev も Decisions も同じ日に最新のモデルで測り直す（ユーザーの決定）。Jev は `JEV_DIRECT_MODEL=jev-1.14.0` で固定する
- 経路は Jev 3 つ（`jev_pointwise`、`_plain`、`jev_crossencode`）と Decisions 3 つ（`decisions_pointwise`、`_plain`、`decisions_crossencode`）。埋め込みと Cohere Rerank は測り直さない
- 判定基準は Decisions に `criteria` の欄がないので `instructions` の末尾に足す。記事に違いとして書く
- 本測定の前に、順序を入れ替える確認をする（合成 5 問、逆順で差の中央値 0.1 以下かつスピアマン 0.8 以上）。通らなければ、まとめる経路を外す
- `refusal` と欠けた答えは 0.0 にしたうえで件数を表示する。応答の `model` と `usage.input_tokens` を両 API で保存する
- `uv.lock` は commit し、README のインストール手順を `uv sync --extra dev` に変えた（ユーザーの決定、9a475a9）。脆弱性の修正は `uv lock --upgrade` を自分で実行して取り込む旨を README に書いた
- 出力は `out/decisions/judge-<dataset>.json`。`results/` と既存の `out/` は変えない

## 捨てた選択肢と理由
- `~/.zshrc` にキーを置いたままにする案: dotfiles リポジトリで管理されており、commit で鍵が漏れる — リポジトリの `.env` に移した
- `feat/strands-decider-comparison` から派生させる案: 記事のリンク先として固定したいブランチで、比較対象も違う — デフォルトブランチから派生させた
- 記事の Jev の結果（`results/`）を再利用して Decisions だけ測る案（Claude の推奨案）: 10 月 14 日に Jev 1.14.0 が出たため、ユーザーが両方を最新で測り直すと決めた — 同じ日に両方を測る
- `jev-latest` で測る案: 2026-10-19 時点で `jev-latest` は `jev-1.13.0` を指し、1.14 は `jev-preview` か `jev-1.14.0` の明示でしか使えない — `jev-1.14.0` に固定する

## ハマりどころ
- `uv sync` は lock にないパッケージを .venv から消す。strands-decider 用に入っていた tokenizers などが消えたので、`feat/strands-decider-comparison` に戻るときは sync し直す
- Decisions の API リファレンスを探した → `/api/reference/llms.txt` に Decisions のページがない → SDK の型定義（`openai/types/decision*.py`）で欄を確かめた
- `cp` で既存ファイルを上書きできなかった → zsh の `cp -i` エイリアスが非対話で止まる → `command cp -f` で上書きした
- ガイドと SDK で画像入力の記述が食い違う（ガイドは data URL のみ、SDK は HTTP(S) URL も可）→ テキストしか送らないので影響なし。資料の README に記録した

## 学び
- Decisions API の応答に所要時間の欄はない。`usage` には `input_tokens` と内訳（`cached_tokens`、`cache_write_tokens`）、`output_tokens`（`reasoning_tokens`）がある
- Decisions は質問 1〜200 問、`choice` は 2〜255 択。課金は入力 $0.10/1M トークンのみ（2026-10-19）
- strands-decider の比較で、まとめる経路はパスを解釈できず当て推量の水準まで落ちた。パス参照の文書化がない API では、順序の入れ替えで確かめてから測る
